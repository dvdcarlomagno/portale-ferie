# Istruzioni per l'agente

Questo repository contiene il Portale Ferie, un'app fittizia per le richieste di ferie e permessi usata nel corso. Il front-end sta in `web/` (React 19, Vite, TypeScript, Vitest con React Testing Library) e l'API sta in `api/` (.NET 10, minimal API con archivio in memoria), con i test in `api.Tests/` (xUnit e WebApplicationFactory). Prima di pianificare una modifica leggete `knowledge/INDEX.md` e i file del dominio coinvolto, applicate le regole confermate in `knowledge/ferie/rules.md` e scrivete prima il test che descrive il comportamento nuovo, verificando che fallisca. Tutti i testi del repository sono in italiano, con il registro di cortesia voi, e i nomi nei dati di esempio sono fittizi: non inserite dati reali, segreti o chiavi nel codice.
